## Maintenance

This documentation is maintained alongside the codebase. When making changes:

1. **Update relevant documentation** for any API or schema changes
2. **Keep examples current** with actual implementation
3. **Update configuration references** when adding new properties
4. **Maintain cross-references** between related documents

## Contributing

When adding new features or making significant changes:

1. Update the appropriate documentation section
2. Add new API methods to the methods table
3. Document any new configuration properties
4. Update database schema documentation for entity changes
5. Add troubleshooting entries for common issues
